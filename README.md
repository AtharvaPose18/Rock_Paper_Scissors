# Rock Paper Scissors Game
A simple Java console-based game where the user plays Rock, Paper, Scissors against the computer.

## Features
- Play against the computer
- Random computer choices
- Determines win, loss, or draw
- Validates user input
- Allows multiple rounds

## Technologies Used
- Java
- Scanner class
- Random class
- Arrays
- Do-while loop
- If-else statements
- Logical operators

## How to Run
1. Download RockPaperScissors.java.
2. Open a terminal in the project folder.
3. Compile the program:
   javac RockPaperScissors.java
   
4. Run the program:
   java RockPaperScissors

## Example Output
Enter Rock,Paper,or Scissors:Rock
You chose:Rock
Computer chose:Scissors
You win!
Do you want to play again(yes/no):no
Thanks for playing!

## Purpose
This project was created to practise Java fundamentals, arrays, random number generation, loops, conditional statements, and string comparison.
